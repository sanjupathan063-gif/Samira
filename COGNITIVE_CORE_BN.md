# SANJU Cognitive Core

এই build-এ নিরাপদ local-first cognitive layer যোগ করা হয়েছে:

- Context awareness
- Risk/confirmation classification
- Goal + resumable task journal
- Action journal
- Capability discovery
- Predictive action history
- Knowledge-graph storage seam
- Declarative Skill Genesis
- Skill rollback
- Resource/network awareness
- Self-diagnostic command layer

## নিরাপত্তা
AI-generated arbitrary JavaScript/Java/native code execute করা হয় না। নতুন skill declarative allow-listed capability হিসেবে তৈরি হয়। Native/device actions-এর জন্য Android permission এবং বিদ্যমান plugins ব্যবহৃত হয়।
